# Dashboard Clima

## Visão geral
Dashboard Clima é uma aplicação front-end feita com React e Tailwind CSS que apresenta informações meteorológicas em um layout limpo e responsivo. A interface foi projetada para mostrar o tempo atual, previsões e dados relevantes de forma visual e acessível.

## Recursos
- Exibição das condições climáticas atuais (temperatura, sensação térmica, umidade, vento).
- Previsão por horas/dias (dependendo da API integrada).
- Interface responsiva, otimizada para desktop e mobile.
- Componentes reutilizáveis construídos com React + Tailwind.

## Stack tecnológica
- React (JavaScript)
- Tailwind CSS
- HTML / CSS
- Integração com API de clima (ex.: OpenWeatherMap, WeatherAPI) — substitua pela API que preferir.

## Rodando localmente
1. Instale dependências:
   ```bash
   npm install
   ```
2. Inicie a aplicação:
   ```bash
   npm start
   ```
3. Abra http://localhost:3000 no navegador.

> Observação: adicione a chave da API de clima em um arquivo .env ou na configuração apropriada antes de rodar a aplicação.
